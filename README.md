# مخاطب‌یار (MokhatabYar)

برنامه فارسی و آفلاین انتقال مخاطبین اندروید با فرمت VCF.

- پشتیبان‌گیری از مخاطبین در یک فایل VCF
- انتخاب فایل و بررسی شماره‌های تکراری پیش از واردسازی
- افزودن فقط مخاطبین جدید، بدون حذف مخاطبین موجود
- کنار گذاشتن مخاطبین مبهم برای بررسی دستی

**احتیاط:** این نسخه آزمایشی است. پیش از انتقال مخاطبین مهم، روی داده آزمایشی تست کنید و یک نسخه پشتیبان مستقل بگیرید.

برای دریافت APK پس از موفق شدن ساخت، از تب Actions خروجی **MokhatabYar-debug-APK** را دریافت کنید.
