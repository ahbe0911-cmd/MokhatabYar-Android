# مخاطب‌یار — نسخه ۱.۱ (ساده و سریع)

**ساخت یک فایل VCF از تمام مخاطبین اندروید، بدون محدودیت انتخاب دستی.**

این نسخه تنها روی گوشی مبدأ نصب می‌شود و فقط مجوز خواندن مخاطبین دارد؛ مخاطبین را تغییر یا حذف نمی‌کند و به اینترنت متصل نمی‌شود.

### کار با برنامه

۱. برنامه را اجرا و اجازه خواندن مخاطبین را بدهید.

۲. دکمه «ساخت فایل همه مخاطبین» را بزنید. مخاطبین قابل دسترس (مثلاً ۵۰۰۰ شماره) به‌صورت جریان داده در یک فایل VCF نوشته می‌شوند.

۳. دکمه «ذخیره فایل VCF» یا «ارسال به گوشی دیگر» را بزنید.

۴. در گوشی مقصد، فایل را با برنامه مخاطبین باز کرده و گزینه Import/وارد کردن را انتخاب کنید. نصب مخاطب‌یار روی گوشی دوم لازم نیست.

### مخاطبین تکراری در گوشی دوم

فرمت VCF به‌تنهایی قابلیت جایگزینی مطمئن مخاطبین فعلی گوشی مقصد را ندارد. برای واردسازی به گوشی دارای مخاطبین مشترک، ابتدا از مخاطبین مقصد پشتیبان تهیه کنید و از قابلیت ادغام/مدیریت موارد تکراری در برنامه مخاطبین مقصد استفاده کنید. این نسخه **هیچ مخاطبی را روی گوشی دوم حذف یا جایگزین نمی‌کند**.

### APK

از [Android APK workflow](../../actions/workflows/build-apk.yml) خروجی `MokhatabYar-debug-APK` را پس از سبز شدن Build از قسمت Artifacts دریافت کنید؛ فایل ZIP را باز کرده و `app-debug.apk` را نصب کنید.

- اندروید ۸ به بالا
- ۱ فایل استاندارد `.vcf`؛ شمارش و نوار پیشرفت
- انتقال از طریق اشتراک‌گذاری سیستم اندروید
- بدون نیاز به حساب کاربری یا اینترنت
- پیش از انتقال واقعی تعداد زیاد، روی یک گوشی آزمایش کنید.
- **هرگز فایل واقعی مخاطبین را در مخزن عمومی GitHub بارگذاری نکنید.**
