# مخاطب‌یار | MokhatabYar

برنامه اندروید فارسی و آفلاین برای انتقال تعداد زیاد مخاطبین با فایل استاندارد VCF.

### امکانات نسخه آزمایشی 1.0
- خروجی تمام مخاطبینِ قابل دسترس به **یک فایل VCF** با فرمت بومی اندروید
- ذخیره فایل و اشتراک‌گذاری با بلوتوث، Quick Share یا پیام‌رسان‌ها
- انتخاب فایل VCF روی گوشی دوم و پیش‌نمایش تعداد مخاطبین جدید، تکراری، مبهم و خطادار
- بررسی شماره‌های ایران با شکل‌های `0912...`، `+98912...`، `0098912...`
- افزودن فقط مخاطبین جدید؛ موارد دارای شماره‌های مشترک/مبهم بدون تغییر باقی می‌مانند
- پشتیبان‌گیری خودکار قبل از ثبت مخاطبین و امکان اشتراک‌گذاری فایل پشتیبان
- بدون اینترنت، سرویس ابری یا تبلیغات

**دقت کنید:** تشخیص تکراری‌ها صرفاً بر مبنای شماره معتبر نرمال‌شده است؛ یکسان بودن نام ملاک ادغام نیست. اگر فردی در یک فایل شماره‌ای قدیمی و شماره‌ای جدید دارد، به‌جای ادغام یا حذف خودکار برای بررسی دستی کنار گذاشته می‌شود. برنامه فیلدهای رایج نام، شماره و ایمیل را وارد می‌کند؛ برای انتقال همه جزئیات مخاطبین از فایل VCF اصلی و واردسازی خود گوشی نیز می‌توان استفاده کرد.

این نسخه آزمایشی است؛ قبل از انتقال اطلاعات مهم، برنامه را با مخاطبین آزمایشی امتحان کنید و نسخه پشتیبان را خارج از برنامه نگه دارید.

### ساخت APK
GitHub Actions در هر Push و همچنین به صورت دستی (workflow_dispatch) تست و APK دیباگ را می‌سازد.

1. به [Actions](../../actions/workflows/build-apk.yml) بروید.
2. Workflow **Android APK** را باز کنید و **Run workflow** را بزنید.
3. بعد از موفق شدن ساخت، در همان Run بخش Artifacts فایل **MokhatabYar-debug-APK** را دریافت کنید.
4. فایل ZIP خروجی Actions را باز کنید تا `app-debug.apk` را نصب کنید.

ابزار محلی: JDK 17، Android SDK 35، Gradle 8.9. دستور: `gradle :app:assembleDebug`.

نام بسته: `ir.mokhatabyar.transfer` — Android 8+.

**هشدار حریم خصوصی:** فایل‌های واقعی VCF یا نسخه‌های پشتیبان را در GitHub آپلود نکنید؛ مخزن ممکن است عمومی باشد.
